## Описание проекта

Двумерная аркадная игра «Астероиды».
Игрок управляет космическим кораблём, уклоняется от астероидов
и уничтожает их ракетами, набирая очки.

## Статус проекта

Создано игровое окно размером 800 × 600 пикселей.
Добавлен корабль: вращение, ускорение, постепенное торможение
и переход через границы экрана.
При включении двигателя отображается пламя.
Движение учитывает время между кадрами.
Реализована стрельба ракетами из носа корабля.
Ракеты летят с постоянной скоростью и имеют ограниченное время жизни.
Астероиды появляются в случайных местах, движутся и вращаются
со случайными скоростями.
При попадании ракеты астероид уничтожается, начисляется одно очко
и показывается взрыв.
Взрыв использует тайловую анимацию: кадры выбираются из общей ленты.
Добавлены три начальные жизни и обработка столкновений корабля
с астероидами. После столкновения корабль возрождается
неподвижным в центре окна.
Добавлены заставка, запуск щелчком мыши и повторное начало игры.
При столкновении, если до него оставалось ноль жизней,
игра завершается. Итоговый счёт сохраняется на экране.

Реализованы неподвижный звёздный фон и полупрозрачный слой
фоновых астероидов, непрерывно движущийся влево.

## Структура проекта

- main.py — запуск игры.
- settings.py — настройки игры.
- game.py — окно и основной игровой цикл.
- objects.py — классы корабля, ракеты, астероида и взрыва.

## Требования к системе

- Python 3.10 или выше.
- Pygame 2.6.1.
- Проверено на Windows.

## Управление

- Стрелка влево — поворот влево.
- Стрелка вправо — поворот вправо.
- Стрелка вверх — включение двигателя.
- Пробел — выстрел ракетой.
- Левая кнопка мыши по заставке — начать новую игру.

## Функциональные возможности

- Управление поворотом и ускорением корабля.
- Постепенное торможение при выключенном двигателе.
- Стрельба ракетами с ограниченным временем жизни.
- Генерация астероидов со случайными скоростями движения и вращения.
- Переход объектов через противоположные границы игрового поля.
- Обработка столкновений, подсчёт очков и жизней.
- Тайловая анимация взрывов.
- Заставка и повторный запуск игры.
- Неподвижный звёздный фон и движущийся полупрозрачный слой.

## Установка и запуск

Откройте папку проекта в VS Code и создайте терминал.
Склонируйте репозиторий:

```bash
git clone https://github.com/milanaarus/asteroids.git
cd asteroids
```

Либо скачайте ZIP-архив через Code → Download ZIP на странице
репозитория и распакуйте его.

### 1. Создание виртуального окружения

Если папка venv уже есть в скачанном проекте, создайте новое
окружение с именем .venv, поскольку готовое окружение с другого
компьютера может не работать.

```bash
python -m venv .venv
```

### 2. Активация окружения в Windows

Для Git Bash:

```bash
source .venv/Scripts/activate
```

Для командной строки cmd:

```bat
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск игры

```bash
python main.py
```

Дополнительные изображения скачивать не требуется:
все графические элементы создаются программой.

## Пример использования

1. Запустите программу.
2. Нажмите левой кнопкой мыши на прямоугольник заставки.
3. Поворачивайте корабль стрелками влево и вправо.
4. Удерживайте стрелку вверх для ускорения.
5. Нажимайте пробел для выстрелов.
6. За уничтожение астероида начисляется одно очко.
7. При столкновении корабля с астероидом теряется жизнь.
8. Если перед столкновением уже было ноль жизней, игра завершается.
9. Нажмите на заставку, чтобы начать новую игру.

Фоновые полупрозрачные астероиды являются декорацией
и не участвуют в столкновениях.

## Обоснование структуры

Программа разделена на четыре Python-файла.
Точка входа находится в main.py, параметры — в settings.py,
игровые объекты — в objects.py, управление игрой — в game.py.
Такое разделение позволяет менять настройки отдельно
от логики и не смешивать запуск программы с описанием объектов.

Классы Ship, Missile и Asteroid наследуются от SpaceObject.
Общий класс содержит перемещение и проверку столкновений.
Класс Explosion отвечает за покадровую анимацию взрыва,
а Game объединяет объекты и обрабатывает события.

## Описание проекта

Двумерная аркадная игра «Астероиды».
Игрок управляет космическим кораблём, уклоняется от астероидов
и уничтожает их ракетами, набирая очки.

## Статус проекта

Создано игровое окно размером 800 × 600 пикселей.
Реализованы основной цикл игры и закрытие окна.
Частота кадров ограничена до 60 кадров в секунду.

## Структура проекта

- main.py — запуск игры.
- settings.py — настройки игры.
- game.py — окно и основной игровой цикл.

## Требования к системе

- Python 3.10 или выше.
- Pygame 2.6.1.
